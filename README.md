# Hyprland-Project
--Installation Guide for Hyprland on Arch Linux Minimal--

Hello everyone, today we’re going to discuss the Hyprland graphical interface, which is available on Arch and NixOS and is guaranteed to work. For any other distribution (not based on Arch/Nix), you may have varying degrees of success. However, since Hyprland is extremely cutting-edge, point-release distros like Pop!_OS, Fedora, Ubuntu, etc., will likely encounter major issues when running Hyprland. Rolling-release distros like openSUSE, Solus, etc., will likely work fine.

**Note : As for Arch Linux Minimal, I’ll go into detail about what you should and shouldn’t include, since the configuration isn’t standard given that the disk will be encrypted.**
